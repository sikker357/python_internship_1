Python CLI Tools 

A collection of simple command-line tools built using Python.

The goal is to understand how real software like git, npm, and docker works internally — starting from scratch.

Features

-Create custom terminal commands
-Argument handling using argparse
-Multi-command support (like real CLI programs)
-Works directly from Windows Command Prompt

Tools Included
1. Calculator Command

Perform calculations directly from the terminal.

Example:

calculator 5 10
calculator 10 3
calculator  4 6
